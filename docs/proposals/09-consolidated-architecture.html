결정 8 영향 (런타임 중립성)

결정 8이 강제하는 어댑터 계층은 일회성 비용으로 영구 보장. Phase 0에서 어댑터 인터페이스 + claude_code + codex 어댑터 1쌍 출시. 이후 모든 Phase는 자동 중립.

결정 8 일회성 비용: ~500 LOC (어댑터 9개 파일 + CI 매트릭스)
이후 회수: 런타임 회귀 자동 차단; 결정 3 자동 만족; 신규 런타임
등장 시 어댑터 1파일 추가 (PR 1건)
