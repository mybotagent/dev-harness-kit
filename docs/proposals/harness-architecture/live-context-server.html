정의

LCS (Live Context Server)는 이 저장소가 직접 배포하는 특정 MCP 서버다. 라이브 상태를 타입이 지정된 URI-addressed 리소스로 노출한다. v1에서 도구는 0개 — 읽기 전용이다.

LCS는 MCP 위에서 동작한다 (MCP ≠ LCS — 자세한 구분은 §3 참조). LCS는 이 저장소의 첫 번째 MCP 서버이며, 두 번째 서버 이후의 adoption 가드를 재정의하는 트리거다 (11-migration-phases.html Phase 1 참조).

LCS vs MCP (결정적 구분)

주장참/거짓
"MCP는 Claude Code 기능이다"❌ MCP는 벤더 중립 프로토콜. Claude Code는 한 클라이언트.
"MCP가 lcs://worktrees 같은 리소스를 정의한다"❌ MCP는 개념만 정의. URI는 LCS의 선택.
"LCS가 MCP 프로토콜이다"❌ LCS는 MCP를 사용하는 한 서버.
"LCS 채택 = MCP 채택"❌ 반대 방향. LCS는 MCP를 요구; MCP는 LCS를 요구 안 함.

비유: MCP는 HTTP이고 LCS는 api.lcs.internal/... — 한 번 만들면 다른 MCP 클라이언트가 모두 접근 가능.

아키텍처

  에이전트 런타임 (Claude Code / Codex)
      │
      │  JSON-RPC over stdio (MCP)
      ▼
  LCS 서버 (`lib/lcs_server.py`)
      │
      ├─► 리소스 핸들러 (8개, `lib/lcs_resources/<name>.py`)
      │
      ├─► 스냅샷 캐시 (5초 TTL, 인메모리)
      │
      └─► 데이터 어댑터 (런타임 무지):
          ├─ git CLI / gh CLI (어댑터 불필요)
          ├─ fs (어댑터 불필요)
          ├─ 런타임 토큰 로그 → `lib/runtime_adapters/tokens.py`
          └─ 런타임 세션 이벤트 → `lib/runtime_adapters/sessions.py`

라이프사이클

  • 부트 (<500ms): 런타임이 세션 시작 시 LCS spawn. 초기 스캔:

git worktree list --porcelain + gh pr list --json ... + ls hooks/*.sh + 런타임 토큰 로그. 병렬.

  • 정상 상태 (<10ms p99): 인메모리 캐시에서 리소스 서빙.

TTL 만료 또는 lcs://invalidate/<uri> 호출 시 갱신.

  • 셧다운: 런타임 종료 시 LCS 종료. 영구 저장소 없음 (v1).

재시작 시 재스캔. v2에서 SQLite 옵션.

  • 실패 모드: 데이터 소스 불가 → status: "partial" + null

필드들. 크래시 아님.

스키마 안정성 계약

URI는 안정적 계약. 페이로드 모양은 버전 관리.

  • 추가 변경 (새 필드): 동일 URI, 버전 bump 없음
  • 호환 깨는 변경 (이름 변경 / 제거 / 타입 변경): 신규 URI

/v<n> 부착. 구 URI는 구 모양 유지.

  • deprecation: 구 URI의 페이로드에 deprecated_at 표시.

두 minor 버전 후 제거.

흡수 위험 (L7)

컴포넌트위험왜
URI 라우팅매우 낮음포맷 고정
리소스 핸들러 (git/gh)매우 낮음실제 I/O, 모델은 합성 불가
스냅샷 캐시낮음포맷 고정 (TTL)
URI 스키마 디자인낮음명시적
런타임 어댑터 (토큰/세션)매우 낮음어댑터 자체는 형식 매핑
데이터 종합 / 추론기각 — LCS는 종합하지 않음—

LCS는 데이터를 보유, 판단은 안 함. 종합은 lib/analysis-core/의 몫 (L7 안전).

런타임 중립성 (결정 8)

LCS의 핵심 (URI 스키마, git/gh 읽기, 캐시 로직)은 런타임 무지다. Claude Code와 Codex에서 동일한 페이로드를 반환한다.

런타임 의존 부분:

  • `lcs://sessions/<id>` — lib/runtime_adapters/sessions.py가

런타임 세션 이벤트를 추상화

  • `lcs://spend/<window>` — lib/runtime_adapters/tokens.py가

토큰 로그 포맷 차이를 흡수

런타임 어댑터가 없거나 실패하면 LCS는 status: "partial"로 응답하며 (셧다운하지 않음) 다른 리소스는 계속 동작.
