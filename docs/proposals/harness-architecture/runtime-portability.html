정의

결정 8: 단일 런타임 종속 = 기각. 모든 신규 컴포넌트는 Claude Code + Codex + 미래 SDK 동등 동작 필수. 한쪽만 동작 = PR 차단.

결정 3 (벤더 종속 배포 = 기각)이 배포 방식을 잠근 반면, 결정 8은 동작 자체를 잠근다. MCP 위에서 만든 서버는 자동으로 결정 8을 만족하지만 (왜? MCP가 모든 런타임의 공통 프로토콜이라서), 런타임 의존 데이터를 다루는 부분은 얇은 어댑터 계층으로 흡수해야 한다.

핵심 원칙

*핵심 (`lib/, bin/`, `hooks/.sh`, 리소스/루브릭 YAML)은 런타임 무지 (runtime-agnostic)**.

런타임별 차이가 필요한 부분은 `lib/runtime_adapters/` 1계층에서 흡수. 어댑터 1개당 200줄 미만. 신규 런타임 등장 시 어댑터 1파일 추가.

신규 SDK 등장 시 <runtime_name>.py 1파일 추가 (인터페이스 메서드 N개 + is_current() 자기 환경 감지).

RuntimeAdapter 인터페이스 (의사)

class RuntimeAdapter(Protocol):
    """런타임 무지 인터페이스."""

    def name(self) -> str:
        """claude-code | codex | future_sdk"""

    def is_current(self) -> bool:
        """현재 환경이 이 런타임인지"""

    def read_token_log(self, window: str) -> TokenLog: ...
    def read_session_events(self, session_id: str) -> list[SessionEvent]: ...
    def hook_event_name(self, neutral_name: str) -> str:
        """PreToolUse -> 'PreToolUse' (Claude) | 'before_tool_use' (Codex)"""
    def prompt_user(self, question: str) -> str: ...
    def workspace_root(self) -> Path: ...
    def install_skill(self, skill_name: str, skill_dir: Path) -> None: ...

런타임 자동 감지: claude_code.is_current() or codex.is_current(). 결정적 — 환경변수 + binary probe + path 의존.

어댑터가 흡수하지 *않는* 것

  • MCP 와이어 호환성 — 모든 런타임이 지원, 어댑터 불필요
  • CLI 명령 (`git`, `gh`, `python3`) — 어디서나 동일
  • 셸 환경 — POSIX 표준에 한정, 런타임 차이 없음
  • `SKILL.md` 본문 — 순수 마크다운, 파서는 어디서나 동일

어댑터가 비대해지면 어댑터 자체가 alpha 위험이 된다. 어댑터는 `is_current()` 외에 분기 없이 추상 인터페이스 1대1 매핑만. 분기 추가 PR은 차단.

CI 매트릭스 (포터빌리티 강제)

.github/workflows/test-portability.yml:

  portability-test:
    strategy:
      matrix:
        runtime: [claude-code, codex]
    steps:
      - setup runtime binary
      - python3 -m pytest tests/test_portability.py
      - inject runtime, assert LCS + hooks + eval + research
        모두 런타임 무지 인터페이스 경유

PR마다 두 runtime lane 모두 통과해야 merge. CI 매트릭스 자체가 결정 8의 결정적 강제 메커니즘.

비용 절감: 핵심 로직은 mock 어댑터로 양쪽에서 시뮬레이션. 실제 런타임 binary는 claude_code.py / codex.py 자체 검증 시에만.

결정 8 vs 결정 3 — 정밀 분리

결정차단 대상차단하지 않는 것
3 (배포 종속)"Claude plugin marketplace만 가능" 같은 설치 방법 종속MCP 위에서 동작하면 양쪽 자동 동작 → OK
8 (동작 종속)"Claude에서만 실행" 같은 런타임 동작 종속양쪽 모두 동작 → OK

두 결정은 보완적: 3은 진입점 잠금, 8은 동작 잠금.

흡수 위험 (L7)

어댑터 자체의 흡수 위험은 매우 낮음:

  • 런타임 토큰 로그 → 통일된 TokenLog 객체 (포맷 매핑)
  • 런타임 세션 이벤트 → 통일된 SessionEvent (포맷 매핑)
  • 추론이 아닌 직렬화/역직렬화. 모델이 흡수할 수 없다.

단, 어댑터가 비대해지면 자체가 위험. 분기 추가 차단 규칙으로 강제.
