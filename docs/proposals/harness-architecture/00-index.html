마이그레이션 단계 (요약)

Phase 0 (포터빌리티) — lib/runtime_adapters/ + CI 매트릭스. 모든 후속 Phase의 선결 조건.

Phase 1 (LCS) — LCS 서버 + 8 리소스 + 스킬.

Phase 2 (훅이 LCS 읽기) — worktree-guard, git-guard 전환. Iron Law L3: 각 PR 본문은 pytest 출력의 마지막 줄 (<N> passed, <N> skipped in <Ns>s 또는 <N> failed in <Ns>s) 패턴을 인용해야 severity gate 통과. PR #319 첫 반복에서 적용됨 (commit 참조).

Phase 3 (평가 확장) — lib/eval_runner.py RUBRIC_REGISTRY + harness/OS 루브릭.

Phase 4 (플랜 가치) — lib/valuation_engine.py + no-go 게이트.

Phase 5 (리서치 강화) — lib/research_engine.py + Phase 0–3 에스컬레이션 + 인용 verification.

Phase 6 (인터뷰) — lib/interview_engine.py + plan 통합.

Phase 7 (하네스 감사) — skills/harness-audit/SKILL.md.

각 단계별 파일 diff + 위험: 11 — 마이그레이션 단계.
