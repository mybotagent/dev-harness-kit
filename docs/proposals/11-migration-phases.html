정의

Backward compatibility (재진입 안전망)

모든 신규 동작은 opt-out:

  • /dev-kit:plan — --skip-interview (영구 플래그)
  • /dev-kit:build — --skip-valuation (영구 플래그)
  • /dev-kit:eval — 신규 차원 opt-in 플래그
  • Hooks — LCS 불가 시 셸아웃 폴백

모든 신규 PR은 하위 호환 유지. 기존 사용자의 워크플로 변경 없음.
